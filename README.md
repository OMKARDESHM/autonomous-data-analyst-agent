# 📊 Autonomous Data Analyst Agent

An AI-powered business intelligence assistant that converts **natural language questions into SQL**, executes them on a PostgreSQL database, generates interactive visualizations, and produces executive business insights.

Built using **LangGraph**, **LangChain**, **NVIDIA NIM**, **PostgreSQL**, **SQLAlchemy**, **Pandas**, **Plotly**, and **Streamlit**.

---

## 🚀 Features

* 💬 Ask business questions in natural language
* 🧠 AI Planner Agent for execution planning
* 📝 AI SQL Specialist for PostgreSQL query generation
* 🛡️ SQL Guardrail to validate generated SQL before execution
* 🗄️ PostgreSQL integration with SQLAlchemy
* 📊 Automatic Plotly visualizations
* 📈 Executive business insights generated by an NVIDIA-hosted LLM
* 🔄 Modular LangGraph workflow with shared GraphState
* 🌐 Interactive Streamlit dashboard

# 🧠 Workflow

### 1. User Query

Example:

```
Show monthly sales by region.
```

---

### 2. Planner Agent

The Planner determines:

* Is SQL required?
* Is visualization required?
* What execution steps should be followed?

Example output:

```
✓ SQL Required

✓ Visualization Required

Execution Plan

1. Query sales
2. Aggregate revenue
3. Create chart
4. Generate insights
```

---

### 3. SQL Specialist

Generates PostgreSQL SQL using the reflected database schema.

Example:

```sql
SELECT
    r.region_name,
    t.month,
    SUM(s.revenue) AS total_revenue
FROM sales s
JOIN regions r
ON s.region_id = r.region_id
JOIN time_periods t
ON s.time_id = t.time_id
GROUP BY
    r.region_name,
    t.month;
```

---

### 4. SQL Guardrail

Before execution, SQL is validated.

Allowed:

* SELECT

Blocked:

* DROP
* DELETE
* UPDATE
* INSERT
* ALTER
* TRUNCATE

---

### 5. SQL Executor

The validated SQL is executed using SQLAlchemy.

Results are loaded into a Pandas DataFrame.

---

### 6. Visualization Agent

Automatically creates an appropriate Plotly visualization based on the returned DataFrame.

Examples:

* Line Chart
* Bar Chart
* Scatter Plot
* Histogram

---

### 7. Insight Agent

Generates an executive summary highlighting:

* Key findings
* Business trends
* Recommendations

# 📊 Example

### Input

```
Show monthly sales in Maharashtra.
```

### Output

Generated SQL

```sql
SELECT
    SUM(s.revenue) AS monthly_sales,
    t.month
FROM sales s
JOIN regions r
ON s.region_id = r.region_id
JOIN time_periods t
ON s.time_id = t.time_id
WHERE r.state='Maharashtra'
GROUP BY t.month;
```

↓

Interactive Plotly Chart

↓

Executive Summary

```
Revenue increased steadily from January to May, with the
highest sales recorded in May. Maharashtra contributed
significantly to regional sales, indicating strong market
performance.
```

The application validates generated SQL before execution.

Current checks include:

* Single SQL statement
* SELECT-only queries
* Blocks destructive SQL operations
* Basic SQL parsing using `sqlparse`

# 💡 Design Decisions

### Why LangGraph?

The application is divided into specialized workflow nodes instead of using one large prompt.

This makes the pipeline easier to understand, debug, and extend.

---

### Why SQLAlchemy Reflection?

The database schema is inspected dynamically.

If tables or columns change, the AI automatically receives the updated schema without modifying prompts.

---

### Why Rule-Based Visualization?

Visualization is implemented using deterministic Python logic rather than another LLM call.

Benefits:

* Faster execution
* Lower API usage
* More predictable charts
* Better performance in GitHub Codespaces

---

### Why GraphState?

GraphState acts as shared memory during one workflow execution.

Each node reads the information it needs and writes its output back into the state.

# 🚀 Installation

Clone the repository

```bash
git clone https://github.com/<your-username>/autonomous-data-analyst-agent.git

cd autonomous-data-analyst-agent
```

Create a virtual environment

```bash
python -m venv .venv
```

Activate it

Linux / macOS

```bash
source .venv/bin/activate
```

Windows

```bash
.venv\Scripts\activate
```

Install dependencies

```bash
pip install -r requirements.txt
```
